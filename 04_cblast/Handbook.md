<a name="core-principles"></a>
## 1. Core Reply Principles

1. **Acknowledge first.** Always thank the sender for reaching out.
2. **Be concise and clear.** Give the exact next step.
3. **Use a warm, professional tone.** Simple English is preferred. If the user writes in Bengali, reply in Bengali or bilingual.
4. **Never share passwords publicly.** Use password reset or a temporary password only when necessary.
5. **Verify before account-specific action.** Ask for registered email, username, or transaction ID when needed.
6. **Use official links and payment numbers only.**
7. **Escalate technical issues.** Do not guess if the problem is server-side.
8. **Use BCC for bulk emails.** Protect recipients’ privacy.
9. **Confirm receipt when required.** For viva, additional assessment, or certificate forms, ask the user to confirm.
10. **End with the standard signature.**

<a name="tone-language"></a>
## 3. Tone & Language

| Situation | Tone |
|---|---|
| New inquiry | Warm, welcoming |
| Payment/registration issue | Clear, procedural |
| Technical problem | Apologetic, reassuring |
| Assignment/viva issue | Firm but supportive |
| Certificate collection | Congratulatory, informative |
| Collaboration/job inquiry | Professional, appreciative |
| Spam/irrelevant | Ignore or short polite decline |

**Do not use:** aggressive language, blame, sarcasm, or over-promising.

<a name="dos-donts"></a>
## 8. Do’s and Don’ts

### Do
- Check spam folder first for missing emails.
- Ask for Gmail ID for Google Classroom.
- Use BCC for bulk emails.
- Confirm receipt for viva/additional assessment.
- Give exact deadlines and contact numbers.
- Send soft copies when requested.
- Keep replies short and actionable.

### Don’t
- Don’t share passwords publicly.
- Don’t promise certificates before evaluation.
- Don’t reschedule classes for one student.
- Don’t reveal other students’ data or email addresses.
- Don’t guess technical solutions.
- Don’t ignore payment verification issues.
- Don’t use aggressive or blaming language.

---

<a name="bulk-email"></a>
## 9. Bulk Email Etiquette

- Use **BCC** for participant lists.
- Use **undisclosed-recipients** when necessary.
- Do not reply-all to student threads.
- Keep subject lines clear:  
  `[Workshop Name] Certificate Collection & Feedback`
- Include only essential links and deadlines.

<a name="ask-more-info"></a>
## 11. When to Ask for More Information

Ask for more details when:
- The user mentions a file but does not name it.
- The payment status is unclear.
- The Gmail ID is missing.
- The certificate name is inconsistent.
- The technical issue is vague.
- The assignment problem is not reproducible.

Template:

```
Dear [Name],

Thank you for your message. Could you please provide the following details so we can assist you better?

1. Registered email/username:
2. Gmail ID used for classroom:
3. Transaction ID/payment proof:
4. Screenshot/error message:
5. Course/workshop name:

Best regards,
Admin
cBLAST, University of Dhaka
```
