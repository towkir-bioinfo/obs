## Claude 101 Course

- [[What is Claude · Claude 101]] — Introduction to Claude as an AI assistant and thinking partner. Covers Constitutional AI, core capabilities (writing, research, coding, reasoning), and the various ways to access Claude (claude.ai, Claude Code, Claude Tag, Claude Design, Microsoft 365).
  - *Tags:* `claude-101`, `introduction`, `capabilities`

- [[Your first conversation with Claude · Claude 101]] — How to start chatting with Claude. Covers the three-part prompt framework (Set the Stage, Define the Task, Specify Rules), adding context via uploads and connectors, iterating on responses, and personalization through Memory and Skills.
  - *Tags:* `claude-101`, `prompting`, `getting-started`

- [[Getting better results · Claude 101]] — Common challenges with Claude responses and how to fix them (too generic, wrong length, wrong format, inaccurate, wrong tone). Introduces the iteration mindset, the 4D Framework, and lightweight evals for evaluating Claude on your workflows.
  - *Tags:* `claude-101`, `prompting`, `troubleshooting`, `evals`

- [[Introduction to projects · Claude 101]] — How to create and use Projects as self-contained workspaces with persistent knowledge, custom instructions, and team collaboration. Covers setup, knowledge bases, RAG scaling, permission levels, and example projects.
  - *Tags:* `claude-101`, `projects`, `knowledge-management`, `collaboration`

- [[Working with skills · Claude 101]] — What Skills are (folders of instructions, scripts, and resources), the difference between Anthropic Skills and Custom Skills, how to enable and create them, and how Skills differ from Projects (knowledge vs. process).
  - *Tags:* `claude-101`, `skills`, `workflows`, `automation`

- [[Connecting your tools · Claude 101]] — How connectors transform Claude into an informed collaborator by giving it access to your tools and data. Covers the Model Context Protocol (MCP), web connectors vs. desktop extensions, setup, practical use cases, and security.
  - *Tags:* `claude-101`, `connectors`, `mcp`, `integrations`

- [[Creating with artifacts · Claude 101]] — What artifacts are (standalone, interactive outputs), common types (documents, code, HTML, SVG, Mermaid diagrams, React components), how to create them, and sharing/publishing options.
  - *Tags:* `claude-101`, `artifacts`, `content-creation`, `sharing`

- [[Research for deep dives · Claude 101]] — How Research mode transforms Claude into a systematic investigator that conducts multiple searches, synthesizes findings, and provides citations. Covers when to use Research vs. web search vs. Thinking vs. enterprise search.
  - *Tags:* `claude-101`, `research`, `citations`, `agentic`

- [[How you'll work with Claude on your desktop · Claude 101]] — The three shapes of work in the Claude desktop app: turn-by-turn Chat, handing work off to Cowork, and building software with Claude Code. Includes a comparison table and guidance on choosing the right mode.
  - *Tags:* `claude-101`, `desktop`, `cowork`, `claude-code`, `chat`
