# OCMT Transgenic Line Registry — BRRI Dhan67 (in planta, OCMT over-expression)

Registry of transgenic BRRI Dhan67 plant lines in which *OCMT* (*Oryza coarctata* metallothionein gene) is over-expressed via the in planta method. Related project: [[02_knocout_os_moc]].

**ID format:** `p-<line>-<sub>`
- Entries with a single number → `p-<number>-1` (e.g. `31` → `p-31-1`)
- Entries already written as `x-y` → `p-x-y` (e.g. `1-2` → `p-1-2`)
