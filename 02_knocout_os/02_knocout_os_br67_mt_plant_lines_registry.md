## Notes

- **Format convention**: Population designation (WT = Wild-Type, MT = Metallothionein transgene) + Generation (T3) + Purpose code (P for panicle) + Line number + Replicate
- **Control**: M1-T3-BR67 background
- **Transgenic**: T3 generation, likely backcrossed into BR67 background
- **Naming scheme** ensures files match plant IDs: use `BR67-T3-WT-P-32-1_` or `BR67-T3-MT-P-2-1_` as filename prefixes for phenotype/expression/growth data
